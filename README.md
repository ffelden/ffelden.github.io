# ffelden.github.io

Personal academic homepage of Fabian Felden, served via GitHub Pages at
[https://ffelden.github.io](https://ffelden.github.io).

Built with the [academic-homepage](https://github.com/luost26/academic-homepage) Jekyll template.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then browse to the displayed local URL (usually `http://127.0.0.1:4000`).
